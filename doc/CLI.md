# Orchestrator CLI 操作ガイド（CLI.md）

本ドキュメントは、Orchestrator 起動後に利用可能な  
**インタラクティブ CLI の操作方法**をまとめたものです。

本 CLI は、PLC シミュレータおよび関連サービスの  
**状態確認・手動操作・障害注入による検証**を目的としています。  
永続的な設定変更や本番運用は想定していません。

本番運用を想定した永続的な制御や設定変更は目的としていません。


## 1. CLI 起動方法

Orchestrator 起動後、標準入力が CLI プロンプトとして使用されます。

```text
orchestrator>
````

## 2. ステータス・情報表示コマンド

### 2.1 プロセス状態確認

| コマンド   | 引数  | 説明     |
| ------------ | --------- | ------ |
| **`status`** | (opt)`-s` | 全プロセスの PID、稼働状態、Ready 状態を表示。<br>`-s` を付与すると稼働サービスの統計情報を表示。 |

### 2.2 PLC メモリ・アドレス確認

| コマンド   | 引数  | 説明     |
| ------------ | --------- | ------ |
| **`addr`** | `<PLC名>`                       | 指定した PLC のアドレス領域構成を表示。                                                     |
| **`info`** | `<PLC名>`<br>(opt)`--watch [n]` | 指定 PLC の全メモリ（X / Y / M / D）状態を表示。<br>`--watch` 指定時は 1 秒周期で自動更新（デフォルト 5 回）。 |



## 3. ログ操作

| コマンド   | 引数  | 説明     |
| ------------ | --------- | ------ |
| **`log`** | なし | 対話型ログビューアを起動。 |



## 4. Chaos（障害注入）コマンド

⚠️ **以下のコマンドは検証用途専用です。**

| コマンド   | 引数  | 説明     |
| ------------ | --------- | ------ |
| **`chaos kill`**   | `<name>`       | プロセスを強制終了。`type: plc` の場合は自動的に再起動。            |
| **`chaos stop`**   | `<name>`       | プロセスを停止し、自動再起動を無効化。                           |
| **`chaos resume`** | `<name>`       | `stop` 状態のサービスを再度有効化し再起動。                     |
| **`chaos delay`**  | `<name> <sec>` | **Modbus 通信遅延を注入。**<br>指定秒数の応答遅延を発生（0 指定で解除）。 |



## 5. 終了コマンド

| コマンド   | 引数  | 説明     |
| ------------ | --------- | ------ |
| **`quit` / `exit`** | なし | 全プロセスを安全に停止して Orchestrator を終了。 |
